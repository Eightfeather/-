整体分区（从上到下、从左到右）：

```
└──────────────────────────────────────────────────────────────────┘
```

**终稿修正（2026-10-23，用户口令）**：
1. 主页右下方**不再有第二组导航键**（原先 `.home-nav` 四个 nav-key 与底栏重复，已删除）。
2. 名片不再单独占一行放在主页内容区，而是**移入底栏主行**：名片在左、4 个导航键在右，四键等分剩余宽度，「一直显示」（与底栏同层，切页保留）。
3. 底栏改为**流式布局**（`#app` flex 纵向：`.view` 占剩余高度、`.dock` 固定在下方，不再 `position:fixed`），因此状态行永远在可视区内，长列表在 `.view` 内滚动、不会被底栏压住。

### 名片（底栏主行左侧，5 个信息块，10 列 × 3 行拼成完整长方形）

内容：
1. 编辑者（玩家自行输入的名字，默认「但丁」）
2. 本编辑器的名字：**边狱工作台（Limbus Workshop）**
3. Mod 数量（全部 Mod，**含被禁用的**，**不含同一 Mod 的多个备份**）
4. DLL 数量（同上口径）
5. 所有 Mod 的总文件体积

终稿排布（单位＝1 列宽 × 1 行高，总 10 列 × 3 行）：

| 位置 | 第 1 行 | 第 2–3 行（竖向跨 2 行） |
|---|---|---|
| 第 1–4 列 | 编辑者名 `(4×1)` | 编辑器名称 `(6×2)`，占第 1–6 列 |
| 第 5–6 列 | 留空 `(2×1)` | 同上（编辑器名称延续） |
| 第 7–8 列 | Mod 数量 `(2×1)` | Mod 总大小 `(4×2)`，占第 7–10 列 |
| 第 9–10 列 | DLL 数量 `(2×1)` | 同上（Mod 总大小延续） |

实现：`.namecard{display:grid;grid-template-columns:repeat(10,1fr);grid-template-rows:28px 1fr 1fr}`，
`.nc-name{grid-column:1/5;grid-row:1}`、`.nc-void{5/7,1}`、`.nc-mod{7/9,1}`、`.nc-dll{9/11,1}`、
`.nc-editor{1/7,2/4}`、`.nc-size{7/11,2/4}`。

### 其他元素

- **导航键**：底栏主行右侧为「主页」「Mod 管理」「Mod 编辑」「Mod 导入」4 个导航入口，四等分、随窗口宽度自动均分。
- **圆形按钮 4 个（右上角）**：设置（本编辑器全部可调项）、指南（使用介绍）、封面（更换左上封面图/内容）、鸣谢（制作组名单）。首版可先只做入口与占位。
- **公告栏**：右上剩余区域，用于放版本更新公告。
- **封面**：先放一张占位图，后续扩展。

## 二、Mod 管理（细化）

- 左栏：已加载 MOD 列表，最下方「＋」创建 Mod。
- 右栏：已加载 DLL 列表。
- 中栏：默认空白；点左/右任一项显示其详情；详情下方 3 个按钮：
  - 启用（绿；已启用时灰色不可点）
  - 备份（黄；默认命名「原名称 + 当前年月日」）
  - 禁用（红；已禁用时灰色不可点）
- **备份版本条**：备份后，点该 Mod/DLL，详情页**上方**出现多个版本页签（显示各备份名，如「备份1/备份2/备份3」或实际备份名）。
- **备份不可直接编辑**：查看备份时是只读的；需点「替换」，把「当前使用版本」与「备份版本」**互换**——互换后原使用版本变成备份、原备份变成当前版本，此时可对当前版本正常编辑。

## 三、Mod 编辑（细化）

- 左栏：Mod 列表，与 Mod 管理同步；禁用的 Mod 整体黑白 + 右下角红 × 角标。
- 右栏：向导 UI，六项：人格编辑 / 被动编辑 / 技能编辑 / Buff 编辑 / 战斗编辑 / 敌人编辑。
- 人格编辑：
  - 先选 12 罪名头像（尽量用原版 UI）；
  - 选后显示该罪人人格列表（仿原版 UI）：
    - 左侧 12 小头像可快速切换罪人；
    - 第 1 项「原版人格列表」，点击展开/收起；
    - 之后依次是本 Mod 该罪人的自定义人格；
    - 最后一项为「＋」空背景人格框，点击新建人格。
- 被动 / 技能 / Buff / 战斗 / 敌人编辑：本稿未细化，先保留占位。
