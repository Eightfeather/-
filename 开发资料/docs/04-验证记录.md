## 三、本轮修复的缺陷（均有复现证据）

1. **所有 POST 接口参数错位**：`api-shared.mjs` 把 `(query, body)` 同时传给处理器，POST 处理器实际收到 query → 定位/建 Mod/保存全坏。修：`method === 'GET' ? fn(query) : fn(body)`。
2. **显式 root 被评分压过**：`locate` 把显式路径与配置候选一起按分数排序，沙箱输给真实私服，导致误写真实私服。修：显式路径可接受即优先返回。
3. **禁用态 Mod 打不开**：人格模块只查 `mods/`。修：新增 `resolveModDir`，同时查禁用区。
4. **虚拟资源 404**：`assets.gen.mjs` 键缺 `web/` 前缀。
5. **界面显示字面量 `${...}`**：模板字符串误用单引号。
6. **PowerShell 写入损坏 JS**：here-string 双引号触发 `${}` 插值。

**问题**：用户报告「用于测试的模块无法被拖动」。用 CDP 真实鼠标事件（Input.dispatchMouseEvent 按下→移动→抬起）复现：dragstart 从不触发（S.dragging 为 null）。此前 UI 验收用的是合成 DragEvent，掩盖了 WebView2 下 HTML5 拖放不可靠的问题。

- 去掉 .module-item 的 draggable，改为指针拖拽：mousedown 记录起点，移动超过 5px 才进入拖拽态（.module-item.selected、#drag-ghost 跟随、elementFromPoint 点亮 .drop-zone.drop-hot），mouseup 落点命中置入区即置入；dragEndedAt 防止误触点击。
- 补充「点选置入」：点击模块即选中（toast 提示），再点任意置入区即可放入。
- 布局：@media (max-width:1600px) 下三栏收窄（.skill-wrap 200/1fr/232、.skill-body 190–220/1fr），窗口默认尺寸改为工作区的 92%（最小 1200×800），在 150% 缩放屏上把 CSS 视口从 1052 提升到 1556，中间编辑区宽度 259→763。

**实测（真实鼠标事件，脚本 数据缓存\cdp-drag2.mjs、cdp-drag3.mjs）**：技能区拖入 / 硬币区拖入 / 点选置入 / 被动区拖入 / Buff 区拖入 全部 PASS；1280 宽下编辑器区域宽度由 105px → 233px，置入区 69px → 197px。

**教训**：UI 验收必须用真实输入事件（Input.dispatchMouseEvent / Input.insertText），合成 DOM 事件只能验证监听器逻辑，不能证明桌面壳里可用。


## 9. 列表滚动位置保持（2026-10-24）

**问题**：Mod 管理里点侧栏靠下的 Mod，左侧列表会跳回顶部。

**根因**：`render()` 每次用 `innerHTML` 整页重建，滚动容器（`.panel-body.list` 等）的 `scrollTop` 随之归零。

**改法**（`src/web/app.js`）：
- 新增 `scrollSelector(el)` / `captureScrollMap()` / `restoreScrollMap(map)`：重绘前把 `#view` 内所有可滚动容器的 `scrollTop` 连同其 CSS 路径（`#view > … :nth-child(n)`）记下，重绘后按同一路径还原；结构变化导致路径失效时静默跳过。
- 只在**同一视图内**重绘时还原（`S._lastView === S.view`），切换页面仍从顶部开始，避免串滚。
- 详情面板 `.detail-body` 明确排除：切换 Mod 时应回到顶部。

**实测（CDP，脚本 `数据缓存\cdp-scroll.mjs`、`cdp-scroll2.mjs`）**：Mod 列表滚到 520 → 点列表第 6 项 → 仍 520 且选中项已切换、详情回到顶部；连续再点第 3 项仍 520；技能列表滚到 180 → 点最后一个技能 → 仍 180；切到主页 `#view` 顶部为 0（不串滚）。
