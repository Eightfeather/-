# 交接文档 · UI 美化（The Lethe Workbench v0.7.0）

> 接手人定位：**只做界面/交互美化**，不要动数据层与写盘逻辑。
> 工程：`E:\辅助文件\Mod编辑器\编辑器正式稿`（仓库根）→ 源码在 `开发资料\`
> 前端只改这三个文件：`开发资料\src\web\index.html`、`app.js`、`style.css`

---

## 0. 先读这一段

1. 这个应用是 **WinForms + WebView2 壳** 里跑一个本地网页，**没有框架**（原生 DOM），样式全在 `style.css`，结构全由 `app.js` 里的 `render()` 拼字符串生成。
2. **不要把 HTML 写进 index.html**：`index.html` 只有底栏骨架与 `#view` 容器；其余屏都是 JS 渲染。
3. 界面里的 `data-act="…"`、`data-view`、`data-*` 属性是**行为契约**。改名/删除会让按钮失联。美化可以改 class、加 wrapper、改 CSS，**不要动这些属性值**。
4. 改完必须自己启动 exe 截图核对，不许只看代码。

## 5. 交互契约（不能破坏）

1. **动作委托**：全局 click 监听读 `[data-act]`，分派到 `actions` 表。按钮上的 `data-act` 值不能改。
2. **导航**：`.dock-item[data-view=home|mods|edit|import]`。
3. **模块画布**：
   - 调色板条目：`data-mb-drag="stmt|value"`（`value` 也可为 `loop` 卡）、`data-mb-kind`、`data-mb-val`/`data-mb-name`。
   - 画布块：`[data-mb-bk="<id>"]`（id 是点号路径，如 `0.1`），`[data-stack="<id>"]` 是缩进容器，`[data-mb-slot="<chain>"]` 是槽，`[data-mb-loop]` 是遍历胶囊槽。
   - 拖拽是**指针事件**（mousedown/mousemove/mouseup），不是 HTML5 drag。别加 `draggable="true"`。
   - 垃圾桶 `.mb-trash` 是几何命中（`pointer-events:none`），改位置时保持 `position:absolute` 在 `.mb-stage` 内。
   - 选中块 `.bk.sel`；锁定块 `.bk.locked`（内部 `pointer-events:none`）。
4. **未保存拦截**：切页/关闭走 `mbGuardDirty` 弹窗（保存并离开 / 放弃 / 取消），样式改它时别删按钮的 `data-act`。
5. **表格类表单**：`data-info="basePower"`、`data-pinfo`、`data-binfo`、`data-field` 等属性是取值键，不能改。

## 6. 与 UI 有关的状态（`window.__WBS`）

页面里有全局 `S` 暴露为 `window.__WBS`，自动化检查可直接读：

- `S.view`（home/mods/edit/import）、`S.selected`（当前 Mod）、`S.editKind`
- `S.status`（`letheRoot/gameRoot/version`）、`S.home.stats`（Mod 数/DLL 数/体积）
- `S.skill / S.passive / S.buff`（当前编辑对象）、`S.module`（当前模块）、`S.mb`（画布状态：`program/search/cat/carry/sel/codePage/hist/redo/savedAt`）
- `S.session`（`dirty/undo/redo`）

三态语义（别混淆）：
- **加载状态**：启用/禁用（禁用仍可编辑，顶部黄条提示）
- **能力状态**：`.wiz.wip` = 未实现（灰化 + 点击提示「该功能正在维修」）
- **数据状态**：`#session-state`（已保存 / 有未保存改动）

## 8. 常见坑

1. `app.js` 是 **ES 模块**，内部函数不在 `window`；自动化只能点 DOM 或读 `window.__WBS`。
2. 修改 `app.js` 请用编辑器/脚本按 `indexOf` 定位后替换，**不要用 PowerShell here-string 写中文**（会乱码）。
3. 构建前必须关进程，否则复制 exe 报 `EBUSY`。
4. 改 CSS 里 `--dock-h` 无效——它由 JS 实测回写；要改底栏高度请改 `.dock` 自身。
5. `.mb-trash` 刻意 `pointer-events:none`，改成 `auto` 会让拖拽删除失效。
6. 新增图标/图片：静态资源放在 `src/web/`（会被内联进 exe），引用用 `/文件名`。

## 10. 你想优先美化的地方（建议顺序）

1. **主页**：封面（可换成真实插画/视频循环背景）、四个圆钮图标、公告栏滚动列表、名片排版细节。
2. **底栏**：导航键的 hover/active 动效、状态行的信息密度。
3. **积木画布**（用户最常用）：帽子形态更接近 Scratch、槽位对比度、拖拽 ghost、垃圾桶吸附动画、分类栏图标化。
4. **三栏编辑页**：列表项信息层级、表单分组、描述区关键词高亮的配色。
5. **弹窗/提示**：统一尺寸与动效、危险操作更醒目。

> 任何视觉改动都不要改变「数据字段名 / data-act / data-* 契约 / 文件写盘行为」。凡是拿不准的，先只改 CSS，不动 `app.js` 结构。
