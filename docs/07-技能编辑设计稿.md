# 07 · 技能编辑（v0.3 设计稿与落地）

> 用户在 m03573 口述、m03615 逐条裁定后的技能编辑器设计；本文件是落地版（含与实现不一致处的说明）。

## 1. 三栏

| 区域 | 内容 |
| --- | --- |
| 左栏 | 技能列表：标题「技能」、搜索框（支持技能 id 与技能名）、按修改日期再按 id 排序、底部「＋新建」与「⇩导入」 |
| 中栏 | ① 技能基础信息（技能名与 id 单独置顶）②「代码 / 描述」切换区 |
| 右栏 | 模块列表：搜索（支持 `[命中时]`/`[使用时]` 前缀与模糊描述）、按修改日期排序；本编辑器内制作的全部模块 |

## 2. 基础信息字段

技能名、技能 id（置顶，id 不可改）、基础威力、硬币数量、攻击修正值、攻击容量、物理属性（SLASH/HIT/PENETRATE/NONE）、罪孽属性（CRIMSON/AZURE/SHAMROCK/AMBER/VIOLET/SCARLET/WHITE/NEUTRAL）、正负硬币技能（positive/negative）。

## 3. 代码区

- **技能置入区**：拖入模块 → 该技能级脚本列表。
- **硬币置入区**：数量 = 「硬币数量」；每格默认「硬币基础信息」= 硬币种类（普通/红/绿/紫）+ 硬币变动值（只填数字，正负由「正负硬币技能」决定）+ 自己的置入区。
- 模块被拖入后以 chip 形式显示，可点 × 移除。

## 4. 描述区

- 纯文本；关键词写作 `[中文名]`（如 `[使用时]`、`[烧伤]`）。
- 实时高亮：命中时点 = 青、命中 buff = 金、未命中 = 红黄底。
- 保存前校验：存在未识别关键词 → 弹「保存检查 / 有错误的关键词输入，请检查拼写」，列出未识别词；可选「返回修改」或「无视风险保存」（无视后原样保留、不做翻译）。
- 时点表与 buff 表**不重合**，分表查找，不做优先级。

## 5. 新建 / 导入

- 新建：id 由用户手填，编辑器对**全库**（原版 + 所有 Mod）查重，重复则拒绝。
- 导入：两条来源——「从原版人格导入」（可搜索人格 → 列出其技能）与「从其他 Mod 导入」。导入后的技能**保持原 id**，意味着一进游戏就覆盖原版；保存前二次确认并标注「原版覆盖」。

## 6. 撤销/保存

- 基础信息与描述：进撤销栈（文件内生效，保存清栈）。
- 代码区（拖拽/硬币）：**不进撤销**（纯拖动，用户裁定）。
- 「保存」当前只清撤销栈；写游戏文件属于下一阶段（见 docs/06）。
