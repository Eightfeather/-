# 03 · 数据契约（Lethe 目录 / 实体 / 本地化 / 备份）

## Lethe 根

以 `D:\私服` 为例：

```
D:\私服\BepInEx\plugins\Lethe\
  mods\<Mod名>\custom_limbus_data\{personality,skill,passive,buff}/*.json
                  custom_limbus_locale\<语言>\{personalityList,skillList,passiveList,bufList}/*.json
                  custom_sprites\*.png
                  custom_appearance\*.bundle
                  custom_buffs\*.txt（0 字节也有效：注册关键词）
  dumpedData\limbus_data\*            原版数据（游戏内按 0 导出）
  dumpedData\limbus_locale\EN\*       原版文本
  ModTemplate\                        新建 Mod 的骨架模板
  LCW\                                 本工具私有（禁用区、备份、项目数据、状态）
```

## 实体与文件

- **实体 ≠ 文件**：一个 json 可以是 `{ "list": [ {...}, {...} ] }` 装多个实体，也可以裸数组/单对象。
  因此编辑按**实体 id**定位，写回时保持原文件与原顺序，只替换对应实体。
- 数据目录名是单数（`personality`），locale 目录名是复数（`personalityList`）。
- 本地化文件是 `{ "<id>": { "id": "...", "name": "...", "desc": "..." } }` 映射。

## 关键字段（人格）

`id, characterId, appearance, rank, hp{defaultStat,incrementByLevel}, defCorrection, minSpeedList[4], maxSpeedList[4], resistInfo, breakSection, mentalConditionInfo, attributeList[{skillId,number}], defenseSkillIDList, ...`

新建人格默认值（与本工具一致）：`rank=1`、`hp.defaultStat=72`、`incrementByLevel=2.48`、`defCorrection=2`、`minSpeedList=[4,4,4,4]`、`maxSpeedList=[6,7,8,8]`、`appearance=<characterId>01_<罪人>_BaseAppearance`。

## id 派生

不同 mod 的派生方式不同，**不要硬编码**：

- 原创人格：技能 id = 人格 id × 100 + 序号（10824 → 1082401）；
- 覆盖式 mod（复用原版人格 id，如 40004000）：技能 id = `unitScriptID` × 1000 + 序号；
- 自制敌人/战斗：可能出现 10 位 id（如 `9029021501`）。

校验以**引用关系**为准（`attributeList[].skillId` 是否存在），而不是公式。

## 骨架按需生长

`ensureLayout(entityType)`：

| 实体 | 数据目录 | 本地化目录 |
| --- | --- | --- |
| 人格 | `custom_limbus_data/personality` | `custom_limbus_locale/EN/personalityList` |
| Buff | `custom_limbus_data/buff` + `custom_buffs` | `custom_limbus_locale/EN/bufList` + `keywordList` |
| 被动 | `custom_limbus_data/passive` + `personality-passive` | `custom_limbus_locale/EN/passiveList` |
| 外观 | `custom_sprites` + `custom_appearance` | — |

新建 Mod 只建 `custom_limbus_data/` 与 `custom_limbus_locale/` 两个空目录。

## 禁用 / 备份 / 事务

- 禁用：`mods/<名>` → `LCW/disabled/mods/<名>`；DLL：`x.dll` → `x.dll.disabled`；状态写 `LCW/state.json`。
- 备份：`LCW/backups/用户保存/<名>_<YYYYMMDD>/`（同日自动 `_2`），自动快照在 `LCW/backups/自动保存/<名>/`。
- 写入：`writeFilesTransactional` = 全部先写临时文件 → 旧文件进快照 → 逐个替换 → 任一步失败按快照回滚。

## 安全边界

拒绝：`..`、绝对路径、盘符、Windows 保留名、名字尾部空格/点、符号链接与 junction、超过 32 MiB 单文件 / 64 MiB 请求体。
