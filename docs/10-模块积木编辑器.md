# 10 · 模块积木编辑器（Scratch 式）

> 版本：0.5.0 起。取代原先「模块元数据表单 + 一行源码」的模块编辑页；现在点击任意模块即进入独立的积木画布。

## 1. 定位

模块＝「一条可被技能/被动/Buff 引用的规则」，最终要被编译成 Modular 脚本。因此编辑器把 Modular 的语法拆成可视积木：

| Modular 语法 | 积木形态 | 说明 |
| --- | --- | --- |
| `/TIMING:WhenUse/` | ⚑ 帽子块「当 使用时」 | 一盏"当绿旗被按下"；一个模块通常一张 |
| `/LOOP:EveryAlly/` | ↻ 帽子块「对每个 友方 循环」 | 块内所有 `Target` 被该目标覆盖 |
| `buff(var_1, var_2, …)` | 效果块「函数名( 槽, 槽 )」 | 参数位是空的插槽，值块可拖入 |
| `IF(a > b):effect:effect` | 「如果 [左] ▾ [右]」+ 内部嵌套区 | 运算只支持 `>`、`<`、`=` |
| `Self` / `Target` / `EveryAlly` | 目标值块 | 可与数量（`AllyExceptSelf99`）配合 |

## 2. 界面

```
[← 返回]  名称 · 前缀   [属性] [查看脚本] [清空] [保存模块]
┌───────────────┬──────────────────────────────────────────┐
│ 分类：时点/循环│  ⚑ 当 使用时                              │
│ 目标/VALUE/效果│  ┌ 如果 [Target] ▾ [VALUE_0]              │
│ /获取          │  │   buff( 槽, 槽, … )                    │
│ ┌ 搜索 ──────┐ │  └                                        │
│ │ 条目 …      │ │                                          │
└───────────────┴──────────────────────────────────────────┘
```

- 左栏调色板按用途分类：**时点 86 / 循环 13 / 目标 13 / VALUE 12 / 效果 124 / 获取 150**（效果含置顶的「如果…则」，获取为带返回值的取值函数）。
- 中栏画布自上而下拼接；语句块可按落点插入任意两行之间。
- 值块（目标 / VALUE / 数字 / 文本 / 取值函数）只能落进插槽；取值函数自身带参数槽，可再嵌套。

## 3. 交互

| 操作 | 行为 |
| --- | --- |
| 拖拽调色板条目到画布 | 插入语句块（落点决定行号） |
| 拖拽值块到插槽 | 填充参数；插槽高亮提示 |
| 点击调色板条目 → 点击插槽/画布 | 点选放置（无鼠标拖拽也能用）；画布空白处追加到末尾 |
| 拖动已有语句块 | 先移除再插入（等于改顺序） |
| 值块 ✎ | 弹窗改数字 / 文本 / 目标数量 |
| 值块 × / 语句块 × | 清空槽 / 删除语句块 |
| Esc | 取消正在搬运的块 |
| 清空 | 二次确认后清空本模块积木（不可撤销） |
| 保存模块 | 写入 `LCW/projects/modules/<id>.json` 的 `program` |

> 纯拖拽产物**不进撤销栈**（与用户约定一致）；重排/删除块同样不可撤销，保存即完成。

## 4. 数据格式（`program`）

```json
{
  "version": 1,
  "builtin": false,
  "blocks": [
    { "k": "timing", "v": "WhenUse" },
    { "k": "loop", "v": "EveryAlly" },
    {
      "k": "if", "op": ">",
      "left": { "t": "target", "n": "Target", "c": null },
      "right": { "t": "var", "n": "VALUE_0" },
      "body": [ { "k": "cons", "n": "buff", "a": [ null, { "t": "n", "v": 3 } ] } ]
    }
  ]
}
```

- 语句 `k`：`timing` / `loop` / `cons` / `if`
- 值 `t`：`target`（`n`=目标名，`c`=数量）/ `var`（`VALUE_0`…`VALUE_9`）/ `n`（数字）/ `s`（文本）/ `acq`（取值函数，`a`=参数槽）
- 校验在服务端 `normalizeProgram()`：`PROG_MAX_NODES=400`、`PROG_MAX_DEPTH=8`、标识符 `^[A-Za-z_][A-Za-z0-9_]*$`、`var` 必须 `^VALUE_\d+$`；不合规即 400。

## 5. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/modular-tables?kind=&q=` | 273 条 Modular 命令表（consequence 123 / acquirer 150，其中 89 条有中文说明） |
| POST | `/api/module/program` | `{ id, program }` → 保存；返回更新后的模块 |
| GET | `/api/module?id=` | 读取模块（含 `program`、`blockCount`） |

## 6. 脚本预览

「查看脚本」按当前积木即时编译：

```
/TIMING:WhenUse/
/LOOP:EveryAlly/
/IF(Target>VALUE_0):buff(_,3)/
```

未填的槽编译为 `_` 占位，便于对照 `docs/09-Modular命令表.md` 的参数说明补全。

## 7. 已知边界

- 目标选择器只开放 13 个常用项（教程族里 `AllyExceptSelf99`、`MainTarget`、`SubTarget` 等尚未进表）。
- 一个模块暂只支持一张「当…时」或「循环」帽子；教程里「一模块多时点」需拆模块。
- 尚未提供积木与「原生技能脚本（scriptName）」的映射——见 `docs/06-待落实：编辑器↔游戏映射.md`。
- 模块列表目前是编辑器全局库（不按 Mod 分区），与技能页共享。
