# 00 · 产品定位与交互约法

## 定位

The Lethe Workbench 是 Lethe（Limbus Company 私服框架）的 Mod 桌面工作台。
它要解决的不是“再写一个 JSON 编辑器”，而是把**从 0 做一个可玩人格 Mod**的整条链路收进一个窗口：

创建 Mod → 选罪人 → 新建人格 → 填数据与文本 → 保存 → 启用/禁用 → 备份/回退。

## 硬约束

1. **单文件桌面应用**：双击出原生窗口；不弹控制台、不打开外部浏览器。
2. **不依赖私服也能启动**：没有游戏/私服时进入“首次设置”，仍可浏览与编辑本地草稿；定位到私服后才读写其 `mods/`。
3. **不依赖旧版编辑器**：与前两版（LE 简单编辑、LBC Mod Creator）完全独立，只继承它们的经验与数据契约。
4. **离线**：不联网、不自动更新。
5. **原版风格**：深色 + 金线、衬线标题、档案式页签；底栏常驻且永远在最上层。

## 三种状态（贯穿所有界面）

| 状态 | 含义 | 表现 |
| --- | --- | --- |
| 加载状态 | Mod 是否会被游戏加载 | 禁用项灰化 + 右下红叉角标；禁用时仍可编辑，详情与编辑页顶部黄色横幅「该 Mod 正在被禁用的状态」 |
| 能力状态 | 该功能是否已实装 | 维修中：保留 UI、降透明度、灰角标「维修中」，点击只弹 toast「该功能正在维修」 |
| 数据状态 | 是否有未保存改动 | 底栏「已保存 / 有未保存改动（撤销 N 步）」；关闭前拦截；保存后撤销栈清空 |

## 主导航（v0.2）

- **主页**：左上封面（占位）、右上四个圆钮（设置 / 指南 / 封面 / 鸣谢，后三占位）、公告栏占位、右下名片五格（编辑者 / 编辑器名 / Mod 数 / DLL 数 / 总体积；上排 3 格，下排第 4 格占 2 格、第 5 格占 1 格）、四个导航键。
- **Mod 管理**：左「已加载 MOD」（底部＋创建）、中详情（默认不显示，选后显示）、右「已加载 DLL」。详情下方居中三按钮：启用（绿，启用时灰）/ 备份（黄，命名 `原Mod名称+年月日`）/ 禁用（红，禁用时灰）。备份后详情上方出现版本页签（当前 + 各备份）。
- **Mod 编辑**：左侧 Mod 列表与 Mod 管理同步（禁用项灰化+红叉）；右侧向导六格：人格 / 被动 / 技能 / Buff / 战斗 / 敌人。
- **Mod 导入**：占位（维修中）。
- **底部栏**：导航行（主页/管理/编辑/导入）+ 状态行（私服根、当前 Mod、数据状态、自动快照、定位/设置、版本），切页不消失，永远在最上层。

## 人格编辑

12 罪人头像（+ 贾惜春）→ 该罪人人格列表：
1. 「原版人格列表」可展开（读 dumpedData，只读参考，带 `原版` 徽标）；
2. 本 Mod 自定义人格；
3. 末尾「＋ 新建人格」。
左侧 12 小头像可随时切换罪人。

## 编辑与版本约法（v0.2 起）

1. **只写改过的字段**：未识别字段原样保留，不做格式重排。
2. **撤销只在文件内生效**：切到别的人格/文件即切栈；Ctrl+Z / Ctrl+Shift+Z。
3. **文件级操作不进撤销**：复制/删除/覆盖/替换/互换/启停，执行前二次确认并明示「无法撤销」。
4. **保存即清栈**：`保存` = 写入磁盘（字段级）+ 清空撤销历史；要回退请用备份或版本互换。
5. **不做跨重启撤销**；异常退出后下次启动提示恢复（操作流水优先，最近快照兜底）。
6. **编辑时请勿手动改文件**：先整批校验再落盘，校验不过提示「撤回失效」。
7. **自动快照**：该 Mod 第一次改动起每 30 分钟一次，整个 Mod 增量镜像到 `backups/自动保存/<Mod名>/` 单槽覆盖；只在有脏改动时执行；不重置撤销栈；左下角 toast 提示（不带“打开位置”按钮——备份/快照只读）。

## 非目标（beta 不做）

章节/剧情编辑、联网与云同步、自动更新、多语言（先 EN）、技能/硬币/Buff 的完整编辑器（后续版本）、历史面板。
