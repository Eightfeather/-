## 构建后端（Node SEA）

```powershell
cd 开发资料
node tools/build-server.mjs
```

步骤：
1. `buildAssets()` 把 `src/web/**` 读成 `build/assets.gen.mjs`（键为 `web/相对路径`）；
2. `buildEntry()` 生成 `build/sea-entry.mjs`：`setAssets(ASSETS); main();`
3. esbuild 打 `build/bundle.cjs`（platform=node, format=cjs, target=node22）；
4. `node --experimental-sea-config build/sea-config.json` → `build/sea-prep.blob`；
5. 复制 `node.exe` → `dist/server/LetheWorkbenchServer.exe`；
6. postject 注入 blob，sentinel fuse `NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2`。

自检：`dist/server/LetheWorkbenchServer.exe version` → `standalone: true`。

## 构建桌面应用

```powershell
node tools/build-app.mjs   # 结束时自动把 exe 复制回项目根
```

步骤：
1. gzip 后端 → `build/payload/payload.server.exe.gz`（约 93 MB → 35 MB）；
2. 复制 WebView2 三个 DLL 到 `build/payload/`；
3. 生成图标 `host/app.ico`（256×256，深底金边 L）；
4. `dotnet build host -c Release -o dist/app` → `dist/app/TheLetheWorkbench.exe`。

## 常见问题

- **构建失败：exe 被占用** → 先 `Stop-Process -Name TheLetheWorkbench,server`。
- **壳启动即退** → 看 `%LOCALAPPDATA%\LetheWorkbench\logs\startup-error.log` 与 `logs\server.log`。
- **界面 404** → 虚拟资源键少了 `web/` 前缀。
- **PowerShell 写 JS 出语法错** → here-string 用单引号 `@'...'@`，避免 `${}` 被插值。
- **写文件用 write 工具报 “file no longer exists”** → 改用 pwsh + `[IO.File]::WriteAllText`（UTF8 无 BOM）。
