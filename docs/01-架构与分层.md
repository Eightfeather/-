# 01 · 架构与分层

## 运行形态

```
TheLetheWorkbench.exe (WinForms + WebView2, net48)
   │  1. 解包内嵌资源到 %LOCALAPPDATA%\LetheWorkbench\runtime\<hash>\
   │  2. 启动子进程 LetheWorkbenchServer.exe serve --no-open --port=0
   │  3. 读子进程 stdout 的 `WB-READY {port,token,letheRoot}` 完成握手
   └─ WebView2 打开 http://127.0.0.1:<port>/?token=<token>
```

- 后端是 **Node SEA 单文件**：`src/**` 用 esbuild 打成 CJS，`src/web/**` 与 `data/**` 内联成虚拟资源（`src/assets.mjs`），`postject` 把 blob 注入 node.exe。
- 前后端在本机回环通信，所有 `/api/*` 需要 `x-wb-token`（启动时随机生成），并校验 Host/Origin，防 DNS rebinding。
- 开发模式不打包：`node src/cli.mjs serve`，前端从磁盘 `src/web` 直接读。

## 后端模块

| 模块 | 职责 |
| --- | --- |
| `src/paths.mjs` | 判断开发态/SEA；解析 `APP_ROOT`、`SRC_DIR`、用户数据目录 |
| `src/config.mjs` | `config.json` 读写（多候选路径、写入前 `.bak`） |
| `src/locate.mjs` | 定位私服：显式 → 配置/最近 → 邻居目录 → 盘符扫描；按结构标记打分（`mods/`、`dumpedData/`、`LimbusCompany.exe` 等），显式路径命中即优先返回 |
| `src/safety.mjs` | `cleanName` / `safeRel` / `resolveInside` / `assertNoLink` / 体积上限 |
| `src/atomic.mjs` | `writeFileAtomic`、`writeFilesTransactional`（临时 → 快照备份 → 替换 → 失败回滚）、`pruneBackups` |
| `src/lethe/layout.mjs` | `ensureLayout(entityType)`：骨架按需生长，统一映射数据目录与 locale 目录 |
| `src/lethe/mods.mjs` | 列出/创建/备份/启用/禁用 Mod；`resolveModDir` 同时解析 `mods/` 与禁用区 |
| `src/lethe/personality.mjs` | 人格实体与本地化文本的读取、派生 id、保存 |
| `src/lethe/vanilla.mjs` | 从 `dumpedData` 读原版人格索引（按罪人过滤） |
| `src/lethe/dlls.mjs` | BepInEx 插件 DLL 列表与启停（改名 `.dll.disabled`） |
| `src/lethe/state.mjs` | `<Lethe>/.lethe-workbench/state.json`（禁用表、快照） |
| `src/server/*` | HTTP 服务、令牌/Host/Origin 校验、路由分发、静态资源、请求体 |
| `src/web/*` | 无框架前端：`app.js`（状态 + 渲染 + 事件）、`index.html`、`style.css` |

## 前端约定

- 单一 `S` 状态对象 + `render()` 全量重绘；事件用 `data-act` / `data-id` 委托，**属性选择器值必须加引号**（`[data-id="1"]`）。
- 三主视图 `mods / edit / import` 由底栏切换，底栏 `position: fixed` 且 `z-index` 最高。
- 模态统一 `.modal`；toast 统一 `toast(text, kind)`。
- 视觉令牌集中在 `style.css` 的 `:root`：底 `#12100E`、面板 `#1C1714`、卡片 `#241D19`、金线 `#C6A15B`、正文 `#E8DCC6`、主红 `#8C1F2B`。

## 数据流

读取：`/api/mods` → `readMod`（扫 `custom_limbus_data/*` 与 `custom_limbus_locale/*`）→ 汇总人格/技能/文件数/体积。
写入：前端提交 `{name,id,entity,locale}` → `personality.save` → `ensureLayout` → `writeFilesTransactional` → 返回 `{changed,written,backups}`。
禁用：移动目录到 `.lethe-workbench/disabled/mods/<name>` 并记 `state.json`；启用反向移动。
